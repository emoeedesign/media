# 設計決定記録（Architecture Decision Records）

このディレクトリには、プロジェクトの重要な設計決定を記録します。

## 目的

- AIツール（Codex・Claude Code）間でコンテキストを共有する
- 「なぜこの設計にしたか」を将来の自分やAIが参照できるようにする

## ファイル命名規則

```
YYYYMMDD-決定内容の短い説明.md
例: 20260315-aiエージェント呼び出し方式.md
```

## ADRテンプレート

新しいファイルを作成する際は以下の形式を使う：

```markdown
# ADR-NNN: タイトル

## 状態
決定済み / 検討中 / 廃止

## 日付
YYYY-MM-DD

## 背景
なぜこの決定が必要だったか

## 検討した選択肢
- 案A: ...
- 案B: ...

## 決定
何を選んだか

## 理由
なぜその案を選んだか

## 結果・影響
この決定が何に影響するか
```
